# Switch-Shadow 🌑

**Switch-Shadow** é um jogo de puzzle 2D focado em raciocínio espacial e posicionamento estratégico. O jogador deve usar a mecânica principal de trocar de lugar com a sua própria sombra para atravessar obstáculos, desviar de espinhos e chegar ao final de cada fase.

Este projeto foi desenvolvido como submissão para a **[That Game Jam #02](https://itch.io/jam/thatgamejam02)**.

🎮 **[Jogue e avalie nosso jogo no Itch.io clicando aqui!](https://itch.io/jam/thatgamejam02/rate/5319802)**

---

## 🧩 Mecânicas Principais

* **Troca de Posição (Switch):** O jogador e sua sombra se movem pelo mapa. A qualquer momento, você pode alternar a sua posição física com a da sombra para alcançar locais antes inacessíveis.
* **Paredes Anti-Troca:** Zonas seguras ou de interferência onde a habilidade de teletransporte/troca é bloqueada, exigindo planejamento de rota.
* **Paredes Alternadas:** Obstáculos de estado que mudam dependendo de qual entidade (Player ou Sombra) está liderando a ação.

## 🛠️ Tecnologias Utilizadas

* **Engine:** [Godot Engine 4.x](https://godotengine.org/)
* **Linguagem:** GDScript
* **Controle de Versão:** Git / GitHub

## ⌨️ Controles

* **Movimentação:** Setas direcionais ou `W` `A` `S` `D`
* **Trocar de Posição:** Tecla `Espaço` (Spacebar)
